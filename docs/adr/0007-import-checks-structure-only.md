# 0007 取り込みは構造だけを確かめ、公理の違反は検証で見せる

2026-10-23 採用

## 状況

取り込む `category.yaml` には、2種類の誤りがありうる。

- 構造の誤り: 必須の項目がない、ID が重なる、存在しないカテゴリや関手を指す
- 圏論の公理の違反: 恒等射がない、射の始点の文書が存在しない、関手が射の向きを保たない

## 決定

取り込みでは構造の誤りだけを弾き、422 で誤りをすべて並べて返す。公理の違反は弾かずに保存し、検証の API と画面で見せる。

## 理由

- 公理の違反を見つけて直すのが、このツールの目的そのもの。取り込みで弾くと、何が違反なのかを画面で見せられない
- 構造の誤りがあると、保存できないか、API でたどれない。たとえば存在しないカテゴリを指す関手は、検証のしようがない
- 誤りを最初の1つで止めずにすべて集めると、YAML を直す人が一度に直せる

## 結果

- 保存したデータには、存在しない文書を指す射のような、公理に反するものが入りうる。読む側はそれを前提にする。グラフの画面は描けない矢印を除き、その誤りは検証の画面で見せる
- 表どうしの参照の整合性は、外部キーではなく取り込みの検査が守る。0006 を参照

## 採らなかった案

- 公理の違反も取り込みで弾く: 上のとおり、目的と合わない
- 構造の誤りも弾かずに保存する: 参照の切れたデータを API の各所で扱う必要が出る
