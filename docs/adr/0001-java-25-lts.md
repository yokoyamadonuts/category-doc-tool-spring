# 0001 Java 25 LTS を使う

2026-10-23 採用

## 状況

2026年10月の時点で、Java の最新は 27、最新の LTS は 25。Spring Boot 4.1 はどちらでも動く。

## 決定

Java 25 LTS を使う。Gradle の toolchain と、実行のイメージ `eclipse-temurin:25-jre-alpine` で版をそろえる。

## 理由

- Spring Framework が全面的にサポートするのは LTS の版だけで、それ以外は動作の確認にとどまる
- 半年で切れる版を選ぶと、サポートの終わりに合わせて上げ続ける手間がかかる
- 使いたい言語の機能、record、パターンマッチ、`List.getFirst` などは 25 にそろっている

## 結果

- 27 で入った機能は使えない。いまのところ困っていない
- 次の LTS が出たら、Spring の対応を待って上げる

## 採らなかった案

- Java 27: 新しい機能は使えるが、Spring のサポートが手薄で、半年でサポートが切れる
- Java 21 LTS: 安定しているが、25 との差を埋める理由がない
